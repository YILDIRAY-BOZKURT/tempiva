Sample data

A backup file with a fictional salon for trying Tempiva.

Backup filetempiva-sample.json

How to load it

  1. Open this page in Safari on the iPhone and tap the file above. It is saved to Files › Downloads.
  2. In Tempiva, go to Settings › Restore from backup and choose tempiva-sample.json.
  3. Confirm the restore. Restoring replaces the data currently in the app.

The file contains 19 customers and 418 appointments for a sample salon. All names and phone numbers (+1 202 555 01xx) are fictional.
